UOM 自动打印是我给日常工作做的一套 Windows 工具。它把实名二维码识别、设备信息整理、标签排版和打印接在一起，主要解决设备一多以后反复截图、裁图、改尺寸、查信息这些很碎的操作。

<!-- more -->

现在它可以处理 UOM 实名码图片和 PDF，也支持设备查询、补打、新设备实名登记和本人设备注销。打印前会重新生成尺寸统一的二维码，再按照实际标签纸输出标签 1 和标签 2。

这篇文章分成两部分：前半段先看成品、我为什么做它，以及我是怎么和 Codex 一步步把它做出来的；后半段再进入实际使用流程。本文以 **UOM 自动打印 v1.2.53** 为例，截图中的姓名、手机号、序列号、照片和二维码均为演示内容。

## 先看成品

<figure class="uom-guide-figure uom-guide-figure--wide">
  <img src="/assets/uom-auto-printer/main-window.webp" alt="UOM自动打印主界面，左侧为标签预览，右侧为UOM官方页面">
  <figcaption>主界面把纸张、标签预览、打印功能和 UOM 官方页面放在同一个窗口中。</figcaption>
</figure>

主界面左边是纸张、标签 1 和标签 2 的预览，右边直接保留 UOM 或 DJI 官方页面。日常操作不需要在多个网页、图片编辑器和打印窗口之间反复切换。

现在这套工具主要完成三件事：

- **接收信息**：导入 PDF 或图片，也可以监听 UOM 账号中的新增登记。
- **整理标签**：识别设备信息，重建清晰二维码，按真实纸张尺寸生成两套标签。
- **完成设备流程**：查询和补打已有设备；新设备按官方流程实名；本人设备核验后注销。

展开来看，它目前支持：

- 导入 PDF、照片或截图，识别有效 UOM 内容并重新生成标准二维码。
- 登录 UOM 后监听新增登记，按设置自动打印或只更新预览。
- 查询已登记设备，复制信息并补打标签。
- 新设备登记时查询 DJI 官方机型，完成 UOM 官方人脸认证后再准备资料。
- 同名机型列出型号代码和重量，由操作人手动确认，不让软件乱猜。
- 分别调整标签 1、标签 2 的内容、张数和布局，并保存个人预设。
- 主窗口收起后通过悬浮窗查看状态或拖入文件。

如果只是偶尔打印一张，手工处理也能完成；如果经常连续处理设备，它省下来的就是那些每天都要重复、又很容易出错的小步骤。

## 为什么会做这个工具

最开始的问题不是“没有软件可用”，而是整个过程太散。

一张实名标签通常要经历：从邮件或网页拿到实名码、截图或下载 PDF、裁出二维码、找设备信息、调整到标签纸尺寸、排版两套标签、选择打印机，最后再检查能不能扫出来。设备少的时候还能手工处理，连续做很多台时，同样的动作会不断重复。

更麻烦的是输入并不统一：有时是 PDF，有时是手机照片，有时是一张留白很多的截图。直接打印原图，每张二维码的大小和清晰度都不一样；换一种标签纸，之前的排版又要重做。

所以我真正想做的不是“再加一个打印按钮”，而是把 **拿到实名信息 → 整理设备数据 → 生成标签 → 核对 → 打印** 这条链路接起来。

## 我是怎么和 Codex 把它做出来的

这不是输入一句提示词，Codex 就一次生成了完整软件。

我负责把真实工作流程、按钮应该放在哪里、什么情况不能自动继续、打印出来应该是什么尺寸这些要求说清楚；Codex 负责读取现有项目、实现功能、修正界面和错误处理。每完成一轮，我再回到 Windows 和真实标签打印场景里测试，把不顺手或不安全的地方继续改掉。

整个过程大致分成几步：

1. 先做最小可用版本，让一张实名码能够变成 60 × 40 mm 标签并正常打印。
2. 把 PDF、截图和照片统一成同一套设备数据，不再分别维护几套打印逻辑。
3. 增加标签 1、标签 2、纸张预设、打印张数和可视化编辑器。
4. 接入查询、监听新增登记和悬浮状态，让连续处理设备时不用一直守着主窗口。
5. 最后才整理实名、同名机型选择、人脸认证、最终确认和注销这些会改变官方数据的流程。

Codex 帮我加快了实现和排查问题的速度，但真实流程、设备信息和最终操作仍然需要人来判断。尤其是打印效果、型号选择和官方提交，不能只看代码“运行成功”就算完成。

## 几个真正难处理的地方

### 不直接打印原图

实名码可能来自网页截图、手机照片或 PDF。原图经常存在拉伸、留白、倾斜和大小不一致的问题，所以软件不会直接把原图贴进标签，而是先提取有效内容，再重新生成尺寸统一的二维码。

如果二维码严重模糊、被裁掉、反光，或者根本不是 UOM 实名码，软件会停止处理并说明原因。我宁愿让它明确报错，也不希望它沿用上一台设备的信息继续打印。

### 排版按照真实纸张尺寸

标签编辑器使用毫米尺寸和安全区排版。小纸张空间不够时，优先保留姓名、手机号、机型、序列号和二维码；纸张大一些，再增加其他信息。

二维码与下方的唯一识别码是一组内容，编辑布局时会一起移动，避免只剩二维码或文字跑出安全区。

### 官方步骤仍然由本人完成

实名登记的主要顺序是：DJI 官方查询机型 → UOM 官方人脸认证 → 匹配 UOM 型号 → 手动确认同名候选 → 查看最终摘要 → 主动确认提交。

> 重复操作可以自动化，但 DJI 滑块、UOM 人脸认证、型号选择、注销和最终提交仍然需要本人操作。软件不会绕过官方验证，也不会替用户确认不确定的信息。

## 从这里开始：第一次使用

开始前需要准备：

- Windows 10 或 Windows 11 电脑。
- 已安装驱动，并且能够打印 Windows 测试页的标签打印机。
- 实际装入打印机的标签纸，并确认宽度和高度。
- 可正常登录的 UOM 账号。
- 办理新设备实名登记时使用的 DJI 账号、产品序列号、整机照片和序列号照片。

**第一次正式打印前，先用演示数据打印一张测试标签。** 先确认纸张方向、边距、二维码清晰度和两套标签的打印张数，再开始连续处理设备。

### 选择打印机和保存目录

    <figcaption>在设置中选择实际打印队列和文件保存目录。</figcaption>
  </figure>
  <figure class="uom-guide-figure uom-guide-figure--compact">

    <figcaption>纸张宽高必须与打印机里实际装入的标签一致。</figcaption>
  </figure>

1. 点击主窗口左下角的 `设置`。
2. 进入 `打印与文件`，选择当前使用的 Windows 打印队列。
3. 选择标签成品保存目录，然后点击 `保存`。
4. 回到主界面顶部，点击纸张区域旁的 `修改`。
5. 选择与实际标签纸一致的尺寸，并检查标签 1、标签 2 的打印张数。

完成标志：重新打开设置后仍能看到正确的打印机和保存目录，主界面的纸张尺寸与实际标签一致。

### 登录账号并测试打印

1. 打开右侧 UOM 官方页面，由本人完成登录。
2. 只做普通导入、查询或打印时，不需要登录 DJI。
3. 办理新设备实名登记时，再打开 DJI 官方页面并登录对应账号。
4. 导入演示实名码，核对两套标签预览后点击 `立即打印`。
5. 用手机实际扫描打印后的二维码，确认能够稳定识别。

首次设置完成应同时满足：打印机选择正确、纸张方向正确、文字没有裁切、二维码可识别、UOM 登录状态正常。

## 日常打印：两种入口

### 监听新增登记

<figure class="uom-guide-figure uom-guide-figure--panel-tall">
  <img src="/assets/uom-auto-printer/auto-print.webp" alt="新增登记监听和自动打印开关">
  <figcaption>适合账号中会连续出现新登记设备的使用场景。</figcaption>
</figure>

1. 确认 UOM 已登录，打印机、纸张和张数均正确。
2. 需要发现新设备后直接打印时，打开 `新增登记自动打印`。
3. 希望先检查预览时，保持自动打印关闭。
4. 点击 `开始监听`。

第一次开始监听时，软件会把当前设备列表记录为起点，不会把已有历史设备全部重新打印。按钮变为 `停止监听`，状态区显示正在等待新增登记，说明监听已经开始。

发现新设备后，软件会读取信息、重建二维码并刷新两套标签。自动打印打开时直接提交到打印队列；关闭时只生成预览，等待点击 `立即打印`。

### 导入图片或 PDF

支持 PDF、JPG、JPEG、PNG、BMP 和 WebP。文件入口和识别结果会在自动打印页面中显示。

<figure class="uom-guide-figure uom-guide-figure--wide">
  <img src="/assets/uom-auto-printer/import-file.webp" alt="导入UOM实名码后，标签预览和打印控件已经刷新">
  <figcaption>识别完成后，标签 1、标签 2、运行状态和打印入口会在同一个页面中更新。</figcaption>
</figure>

1. 点击 `导入实名码`，或者把文件拖入自动打印页面或悬浮窗。
2. PDF 有多页时，选择真正包含 UOM 实名二维码的页面。
3. 等待标签 1、标签 2 的预览刷新。
4. 核对姓名、手机号、机型、序列号和唯一识别信息。
5. 检查纸张尺寸与打印张数，然后点击 `立即打印`。

二维码被裁掉、遮挡、反光严重，或文件中不是 UOM 实名码时，软件会停止处理。重新准备一张边缘完整、清晰、反光较少的图片后再次导入。

## 查询、补打和注销

### 查询已有设备

<figure class="uom-guide-figure uom-guide-figure--panel-tall">
  <img src="/assets/uom-auto-printer/device-query.webp" alt="设备查询结果、复制信息和打印入口">
  <figcaption>查询、打印和注销是三件不同的事。</figcaption>
</figure>

<figure class="uom-guide-figure uom-guide-figure--panel">
  <img src="/assets/uom-auto-printer/scanner-input.webp" alt="信息查询页的序列号输入和导入机身实名码入口">
  <figcaption>当前版本的查询入口是序列号输入或导入机身实名码，并没有单独的扫码输入卡片。</figcaption>
</figure>

1. 切换到 `信息查询`。
2. 输入产品序列号，或按界面提示导入设备实名码。
3. 点击 `查询`，等待结果卡片出现。
4. 核对机型、序列号、登记状态和可见的官方参数。

查询成功后可以：

- 使用 `复制信息` 按当前卡片排版复制可见内容。
- 在能够生成有效标签时点击 `打印` 完成补打。
- 查看设备是否属于当前登录的 UOM 账号。

公开查询到设备不代表当前账号拥有注销权限。注销只允许处理当前账号本人名下的设备。

如果扫码枪工作在“键盘输入”模式，也可以先把光标放进序列号框，再扫描能够直接输出飞行器序列号的条码。这里接收的是序列号文本，不是任意 UOM 二维码；当前 v1.2.53 也没有“识别后自动清空扫码框”的独立功能。

### 注销本人名下设备

<figure class="uom-guide-figure uom-guide-figure--panel">
  <img src="/assets/uom-auto-printer/device-cancellation.webp" alt="实名注销区域完成当前账号归属核验后的状态">
  <figcaption>只有核验为当前 UOM 账号本人名下的设备，才会进入注销确认。</figcaption>
</figure>

1. 进入 `实名/注销` 页面底部的注销区域。
2. 输入界面要求的唯一识别码、产品序列号或设备编号。
3. 点击查询或注销按钮，等待账号归属核验。
4. 本人设备会显示注销确认，核对设备后再继续。
5. 非本人设备会停止操作，不会进入注销提交。

注销会改变 UOM 中的实际设备状态，确认前务必再次核对设备信息。

## 新设备实名登记

### 准备序列号和照片

<figure class="uom-guide-figure uom-guide-figure--portrait">
  <img src="/assets/uom-auto-printer/registration-prepare.webp" alt="实名登记序列号、整机照片和序列号照片准备区域">
  <figcaption>先准备产品序列号、整机照片和序列号照片。</figcaption>
</figure>

1. 进入 `实名/注销`，输入产品序列号。
2. 把清晰的整机照片放入第一个照片框。
3. 把能够看清序列号的照片放入第二个照片框。
4. 确认两个缩略图没有放反，然后点击 `识别并认证`。

照片支持 HEIC、HEIF、JPG、JPEG、PNG 和 WebP。HEIC 或较大的图片需要更长的读取时间，预览仍在加载时不要反复点击。

### 识别机型并选择同名候选

软件会打开 DJI 官方查询页面并填写序列号。需要登录或滑块时，由本人在右侧官方页面完成。

名称相同并不代表型号代码和重量相同。出现多个候选时，软件会暂停后续流程，等待操作人选择。

<figure class="uom-guide-figure uom-guide-figure--panel-tall">
  <img src="/assets/uom-auto-printer/model-selection.webp" alt="同名机型候选列表，显示型号代码、重量和选好了按钮">
  <figcaption>同名候选必须核对型号代码、空机重量和最大起飞重量，再点击“选好了”。</figcaption>
</figure>

如果一个产品名称对应多个 UOM 型号：

1. 查看候选卡片中的型号代码。
2. 对照空机重量和最大起飞重量。
3. 点击整张卡片选择正确型号。
4. 确认选中状态正确后点击 `选好了`。

无法判断时，应查看机身、说明书或官方资料。候选没有确认前，软件不会继续准备最终提交。

### 完成人脸认证

<figure class="uom-guide-figure uom-guide-figure--panel">
  <img src="/assets/uom-auto-printer/face-verification.webp" alt="UOM微信和支付宝官方人脸认证入口">
  <figcaption>默认使用微信，也可以在界面提供入口时切换支付宝。</figcaption>
</figure>

1. 软件展示 UOM 官方动态返回的认证码后，使用当前 UOM 账号对应的实名人扫码。
2. 在手机上完成官方页面要求的操作。
3. 等待电脑端显示认证通过。
4. 二维码窗口被关闭后，可点击 `重新打开认证`。
5. 显示 `继续提交` 时，表示人脸已经通过，但登记资料尚未最终提交。

### 核对最终摘要再提交

<figure class="uom-guide-figure uom-guide-figure--compact">
  <img src="/assets/uom-auto-printer/registration-confirm.webp" alt="实名登记提交前的最终信息确认窗口">
  <figcaption>最终提交前逐项核对机型、序列号、重量和照片。</figcaption>
</figure>

准备完成后，最终摘要会列出登记人、机型、产品序列号、重量、用途、生产日期和两张照片。

确认所有信息无误后，由当前操作人主动点击绿色 `确认提交`。任何一项不确定，都应点击白色 `取消` 返回检查。

提交较慢时不要重复点击。结果不明确时，先打开 UOM 官方设备列表，用序列号确认是否已经登记成功；只有确定没有记录时才重新尝试。

## 标签模板、悬浮窗和文件保存

### 调整标签纸和模板

<figure class="uom-guide-figure uom-guide-figure--wide">
  <img src="/assets/uom-auto-printer/label-editor.webp" alt="标签可视化编辑器、安全区和个人预设">
  <figcaption>标签 1 和标签 2 可以分别编辑，但共用同一个纸张尺寸。</figcaption>
</figure>

1. 在主界面顶部点击 `修改`，选择实际标签纸尺寸。
2. 点击 `编辑` 进入标签编辑器。
3. 在标签 1 和标签 2 之间切换，拖动元素或调整大小。
4. 保证姓名、电话、机型、序列号和二维码位于安全区内。
5. 点击 `保存`，输入个人预设名称。
6. 返回主界面，在 `修改 → 我的预设` 中选择刚保存的预设。

保存编辑内容不会自动替换当前纸张，必须回到主界面主动选择。修改布局后先打印一张测试标签，并用手机实际扫码。

### 使用悬浮窗并正确退出

<figure class="uom-guide-figure uom-guide-figure--mini">
  <img src="/assets/uom-auto-printer/floating-status.webp" alt="UOM自动打印悬浮状态窗口">
  <figcaption>悬浮窗显示等待、读取、生成、打印、完成和错误状态。</figcaption>
</figure>

悬浮窗可以在不占用完整桌面的情况下查看状态，也支持直接拖入二维码图片或 PDF。点击悬浮窗可以回到主窗口，它会记住最后一次放置的位置。

标签文件保存目录可在 `设置 → 打印与文件` 中修改。默认目录为：

```text
桌面\UOM实名登记标识
```

只有真正执行打印后才会生成 PNG 和精确尺寸 PDF，仅切换纸张或刷新预览不会产生多余文件。

点击主窗口右上角的 `×` 通常只是收起窗口，监听可能仍在继续。需要彻底退出时：

1. 点击 `停止监听`。
2. 找到 Windows 托盘中的 UOM 自动打印图标。
3. 打开托盘菜单并选择 `退出程序`。
4. 确认悬浮窗和托盘图标都已经消失。

## 常见问题

**设置里找不到打印机**

先在 Windows 的 `打印机和扫描仪` 中确认打印机存在、不是脱机状态，并能打印测试页。随后重新打开软件设置选择打印队列。

**标签方向或尺寸不正确**

核对实际纸张宽高，在主界面 `修改` 中选择相同尺寸，同时检查打印机驱动是否又做了一次缩放。

**二维码图片或 PDF 无法识别**

确认二维码来自 UOM 实名信息；PDF 多页时重新选择正确页面；重新截图时保留二维码四周边缘，避免反光、阴影、裁边和过度倾斜。

**查询不到设备**

重新核对序列号中的字母和数字，确认 UOM 页面仍然登录。新登记数据可能需要等待官方页面更新；如果公开查询只有基础信息，可改为导入官方实名码。

**DJI 页面要求登录或滑块**

在软件右侧的 DJI 官方页面中由本人完成登录和滑块。不要切换到另一个浏览器处理，因为登录状态可能不属于同一个页面会话。

**同名型号不知道怎么选**

对照型号代码、空机重量和最大起飞重量，查看机身、说明书或官方产品页面。仍无法确认时先取消，不要提交一个“看起来差不多”的型号。

**照片无法预览或 HEIC 一直等待**

先等待图片读取完成，确认文件能在 Windows 中正常打开。仍然失败时，可另存为清晰 JPG 后重新添加，并检查两张照片是否放反。

**人脸认证二维码被关闭**

保持本次序列号和照片不变，点击 `重新打开认证`。如果已经修改序列号或照片，需要重新执行 `识别并认证`。

**实名提交等待时间较长**

只要界面仍显示处理中就继续等待，不要重复点击。结果不明确时，先到 UOM 官方设备列表核对序列号是否已经登记成功。

**无法注销设备**

确认当前登录的是设备所有人的 UOM 账号，并核对输入的序列号或唯一识别码。非当前账号本人名下的设备不能注销。

**打印完成但没有找到文件**

在 `设置 → 打印与文件` 查看实际保存目录，并确认打印任务确实已经提交，而不是只生成了预览。

**点击 `×` 后软件还在运行**

`×` 用于收起主窗口，不等于退出程序。先停止监听，再从 Windows 托盘菜单选择 `退出程序`。

日常使用可以记成一条很简单的顺序：**选择纸张 → 获取或查询设备信息 → 核对预览 → 打印**。实名登记和注销会改变 UOM 中的实际设备状态，操作时始终以最终确认窗口和官方页面显示的信息为准。
